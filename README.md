# Proyecto Integrador – ENPH

## Desarrollo de un software para apoyar la recolección y seguimiento de hogares – Cuadernillo 2 urbano de la ENPH

### Descripción del proyecto

Este proyecto integrador tiene como finalidad desarrollar un software que apoye el proceso de recolección y seguimiento de la información correspondiente al Cuadernillo 2 urbano de la Encuesta Nacional de Presupuestos de los Hogares (ENPH), realizada por el Departamento Administrativo Nacional de Estadística (DANE).

El software estará orientado a facilitar la organización de los hogares asignados a los encuestadores, el seguimiento de las visitas durante los 14 días de recolección, el registro de los gastos del hogar y la revisión de la información obtenida.

El proyecto integra conocimientos de las asignaturas Ingeniería de Software I, Bases de Datos II y Programación II.

### Objetivo general

Desarrollar un software para apoyar el proceso de recolección del Cuadernillo 2 urbano de la ENPH, integrando el modelado de requisitos, una base de datos relacional y programación orientada a objetos, con el propósito de facilitar el seguimiento de los hogares durante la recolección.

### Objetivos específicos

1. Analizar el proceso de recolección del Cuadernillo 2 urbano de la ENPH a partir de las necesidades y funcionalidades requeridas por el software para el seguimiento de los hogares.
2. Diseñar el software a partir del análisis realizado, considerando de manera integrada su estructura, comportamiento y modelado de la información mediante una base de datos.
3. Implementar el software a partir del diseño propuesto y de las funcionalidades definidas para el seguimiento de los hogares.

### Actores del software

- **Recuentista:** identifica las viviendas y hogares y registra su información básica.
- **Supervisor:** realiza la asignación de hogares, supervisa el avance de los encuestadores y revisa el trabajo de campo.
- **Encuestador:** desarrolla la aplicación del Cuadernillo 2, realiza las visitas y verifica la información recopilada.
- **Jefe del hogar:** participa proporcionando información y registrando los gastos diarios durante el periodo de recolección.

### Funcionalidades previstas

- Realizar el recuento inicial de hogares.
- Asignar hogares a los encuestadores.
- Supervisar el trabajo de los encuestadores.
- Aplicar la encuesta correspondiente al Cuadernillo 2.
- Realizar seguimiento de las visitas.
- Verificar la identificación del hogar.
- Caracterizar el gasto en alimentos del hogar.
- Recopilar los gastos diarios del hogar.
- Registrar comidas preparadas fuera del hogar.
- Revisar los gastos diarios registrados.
- Finalizar la recolección de los hogares.
- Revisar el trabajo de campo e identificar correcciones pendientes.

### Tecnologías y herramientas

- **Java:** lenguaje de programación orientado a objetos.
- **Apache NetBeans:** entorno de desarrollo del software.
- **Oracle o MySQL:** alternativas contempladas para la implementación de la base de datos relacional.
- **Astah:** elaboración de diagramas UML.
- **GitHub:** almacenamiento y control de versiones del código fuente.
